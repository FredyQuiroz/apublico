# Atención por turnos / Service queues

[Español](#español) · [English](#english)

## Español

Ejercicio de consola en C++ para organizar turnos. Cada sección tiene su propia cola, lo que permite distinguir a las personas que esperan atenciones diferentes.

### Qué puedes hacer

- Registra a una persona en la cola de una sección.
- Consulta quién está esperando y toma el siguiente turno.
- Conserva variantes de C++ para distintos entornos de la época.

### Ejemplo

Agrega dos personas ficticias a la misma cola y atiende un turno. Comprueba en el código qué elemento sale de la cola.

### Cómo empezar

El código es C++. Abre la solución histórica de Visual C++ que acompaña al ejercicio y comprueba las bibliotecas indicadas por el proyecto antes de compilar.

Puntos de entrada en el código. [`apublico.sln`](apublico.sln), [`apublico.vcproj`](apublico.vcproj).

Las fechas del historial se apoyan en Git o en la evidencia disponible de los respaldos. Las fechas reconstruidas a partir de archivos sin zona horaria usan las 12:00 UTC como referencia.

## English

A C++ console exercise for organizing service turns. Each section has its own queue so people waiting for different services can be tracked separately.

### What you can do

- Add a person to a section's queue.
- See who is waiting and take the next turn.
- Preserves C++ variants for different historical environments.

### Example

Add two fictional people to one queue and serve one turn. Follow the code to see which entry leaves the queue.

### Getting started

This is C++ source. Open the historical Visual C++ solution supplied with the exercise and check the libraries listed by the project before building.

Entry points in the source. [`apublico.sln`](apublico.sln), [`apublico.vcproj`](apublico.vcproj).

History dates come from Git or available backup evidence. Reconstructed dates from files with no time zone use 12:00 UTC as a reference.
